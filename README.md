**Customer Shopping Behavior Analysis**

This is an end-to-end **Data Analytics project** where I analyzed customer shopping behavior using **Python, SQL, and Power BI**.

**Tools Used**

**Python (Pandas)** – Data cleaning and preparation
**MySQL** – Data analysis and business queries
**Power BI** – Dashboard and data visualization
**Jupyter Notebook** – Python analysis

**What I Analyzed**

* Customer and revenue trends
* Product and category performance
* Customer segmentation
* Discount and subscription behavior
* Payment and shipping preferences
* Customer review ratings
* Top-performing products

**Project Workflow**

**Raw Data → Python Data Cleaning → MySQL Analysis → Power BI Dashboard → Business Insights**

**Project Files**

* `Python` – Data cleaning and preparation notebook
* `SQL` – SQL queries used for analysis
* `PowerBI` – Power BI dashboard
* `Dataset` – Dataset used for the project
* `Report` – Detailed project report

**Dashboard**

The Power BI dashboard provides an interactive view of the key findings using **KPIs, slicers, charts, and customer/product analysis**.
